# Local Book Engine & Study Desktop App

A high-performance, local-first reading and study platform built with Tauri v2, TipTap, SQLite FTS5, and Python.

## Structure
- `.agent/skills/`: Autonomous validation harnesses
- `apps/desktop/`: Tauri v2 desktop client
- `packages/ingestion/`: Python parsing and salience pipeline
- `vault/`: Plain-text books, notes, and assets
